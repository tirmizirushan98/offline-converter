# Offline Converter

Convert PDF, Word, Excel, PowerPoint and images, and make exact-size visa/passport photos,
**entirely in your browser**: files are never uploaded. Live at https://rushantirmizi.com

This repository holds the published web app only; it is deployed automatically by GitHub Pages.
Bundled libraries in `vendor/` keep their own licences (pdf-lib, pdf.js, SheetJS, mammoth, JSZip, html2pdf.js).
